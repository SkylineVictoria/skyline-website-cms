## Cutover sequence

1. Verify which function definitions, storage settings and settings rows are live. Record each active enforcement point and the actor and outcome it protects.
2. Confirm the classification with SLIT before moving a value. For a mandatory floor or rule, record the authority, operational applicability and effective dates independently of any institutional default.
3. Register the current value as an unapproved draft, add regression tests and keep the old workflow effective until SLIT approves a replacement. Use a staged deployment for changes spanning multiple workflows. Mark existing settings as authoritative during the transition and avoid parallel editing surfaces.
4. When activated, compare the actual backend result and each portal with the prior behavior using approved fixtures. Retire redundant operational fallbacks only after published configuration exists and missing configuration fails safely.
