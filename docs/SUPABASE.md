## HRMS (Victoria): time & attendance, pay schedules, leave, public holidays, Xero export (HRMS-01, 2026-11-10)

Fixed decisions (owner): Victoria, timezone `Australia/Melbourne` in `hr.settings` (never an offset in code); every instant is timestamptz; hours worked = elapsed time; work date = Melbourne date of the punch-in (night shifts belong to their start day); pay-period boundaries = local midnight; employment types stay full_time | part_time (no casuals); punches from desktop and mobile web only (no agent, screenshots, geofence, reimbursements); payroll (PAYG, super, STP, payslips) is calculated in Xero, Skyline exports approved hours, leave and holidays per period; weekend and public-holiday shifts are allowed but flagged; no import from the old HRMS.

Conventions: every new table in `hr` has RLS on and no grants to anon/authenticated; all access goes through SECURITY DEFINER RPCs in `public` (`search_path = public, hr, pg_temp`). HR admin = `hr.require_admin()` (cms_is_admin). Manager = `hr.employment.manager_id`. Active staff = `hr.staff_profiles.status = 'active'`; the signed-in person's record is `hr.me_profile()`. Decisions (time corrections, leave, timesheet approvals) go through `hr.require_decider(profile)`: HR or the manager, never one's own record (an admin who is also an employee asks another admin for their own).

- Settings `hr.settings` (one row): timezone, state (VIC), ordinary_hours_week 38, open_shift_flag_hours 14, usual_work_days {1..5}, breaks_paid false. RPC `hr_settings()` (any signed-in person), `hr_admin_settings_save(jsonb)`.
- Time `hr.time_events` (append-only; trigger blocks UPDATE/DELETE/TRUNCATE): kind punch_in | break_start | break_end | punch_out | void; source web | mobile | correction; `supersedes` (one correction per row; a correction of a correction supersedes the correction); reason required for corrections.
